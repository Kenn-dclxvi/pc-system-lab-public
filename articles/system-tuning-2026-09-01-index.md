# 自作PCチューニング記録

設定値を探す場合は、[このPCのBIOS・アプリ設定](./system-tuning-settings.md)へ。CPU・GPU・ファンなど、見たい項目から直接確認できます。

自作PCのAIO故障をきっかけに冷却系を見直し始めました。

最初はAIOを直して、ついでにケースファンを整理するくらいのつもりでした。ところが実際に温度や回転数を測り始めると、ケース内の空気の流れ、RTX 3080の約350 Wという発熱、長時間負荷で出るCPUのWHEAと、次々に別の課題が見えてきました。

測る対象はケース冷却からGPUのV/F調整へ移り、さらにCore i9-10900KのTurbo、TVB、Adaptive Voltage、V/F Curveまで確認することになりました。

今回、5年前と大きく違ったのは、AIエージェントを使って進めたことです。

設定の意味を調べるだけではなく、測定前の条件確認、ログの収集、過去の試験との比較、WHEAやWindows Event Logの確認、次に試す条件の整理まで一緒に回しました。どれも人間だけでできる作業ですが、毎回全部やるにはかなり重いです。今回はその部分を任せられたので、「気になるけど、調べるのが大変だからここで終わり」がかなり減りました。

この記録は、設定値の一覧ではなく、**何が気になって、何を測って、どう判断して次へ進んだか**を記録したものです。最初の3本とエピローグに加え、その後にワット当たり性能を見るようになった続編と、完成したPCを4K最高品質で見直した記事を追加しました。ファンの確認から再開した電圧調整は4本、その後のブラウザでの倍率比較とCPU検証の締めくくりは3本に分けています。並行して進めたGPUの750 mV化とDLSSの話も加えました。各記事には、その場面でAIエージェントをどう使ったかも書いています。

## これまでの調整のまとめ

### [ケースの冷却を確かめてから、UVとファンの下限を詰める](./system-tuning-cooling-after-undervolt.md)

ケースの冷却確認、CPU・GPUの低電圧化、長時間試験の結果が、ファンの下限調整にどうつながったかをまとめています。個々の試行は、以下の記事で順に追えます。

## 1. ケース・冷却編

### [AIO故障から、必要な分だけ回す冷却へ](./system-tuning-2026-09-01-case-cooling.md)

AIO故障をきっかけに、ケースファンと水冷系を一度全部見直しました。

Rearを100%まで回して上限を測り、Bottomは止めてもGPU温度がほとんど変わらないことを確認し、KrakenはCPU温度ではなくLiquid温度を見る構成へ整理しました。

テーマは、**強く回すことではなく、必要な冷却を保てるところまで回転数を下げること**です。

### 補足：[GPUの前に導風板を入れてみる](./system-tuning-case-air-guide.md)

前面と底面から入る風をGPUへ向けようと、段ボールで水平の仕切りを作りました。付け外しでは小さな差が出ましたが、底面ファンを強くしても止めてもGPU温度はほぼ同じ。プラ板に作り直したあと、上側の暖かい空気が下りにくくなる働きが気になり始めました。

## 2. GPU編

### [約3%の性能と引き換えに、RTX 3080の消費電力を約100 W下げる](./system-tuning-2026-09-01-gpu.md)

FF14のスコア低下が冷却によるものかを切り分け、Hypervisor / VBSの影響を確認したあと、RTX 3080のV/F Curveを調整しました。

1905 MHz / 825 mVは失敗。850 mVへ戻すと短期ベンチは安定し、Scoreは約3.35%下がる一方で平均GPU Powerは約98 W下がりました。

ただ、長時間試験は59分で落ち、その前にはCPU/cache系のWHEAも出ていました。

## 3. CPU・BIOS編

### [5.3 GHzを追うところから、5 GHzを実用域にするところへ](./system-tuning-2026-09-01-cpu-bios.md)

長時間試験のWHEAを受けて、まずTurbo Ratioを全段1bin下げて安定性を確認しました。

そこからIntel本来のTurbo / TVB動作を調べ、5.3 GHzがPreferred Coreの限定的な動作点だと確認。Adaptive VoltageとV/F Pointを実測し、ASUS Overclocking TVB +1も試しました。最終的には5.3 / 5.4 GHzを追うのをやめ、4～10コア使用時を5.0 GHzにし、その5.0 GHz付近のV/F Pointを下げる方針へ切り替えました。

現時点では、5.0 GHzを全10コアで使いながら、平均CPU PowerをManual 1.300 V時の85.00 Wから81.25 Wまで下げています。

## 続編

### [最適なコア数を探すところから、FF14で使う電力を選ぶところへ](./system-tuning-2026-09-03-cpu-efficiency.md)

当初はFF14に効く物理コア数を探し、そのコアを高く回すつもりでした。ところが6コア、10コアで倍率を下げながら測るうちに、最高Scoreよりワット当たり性能を見るようになりました。

6コアで性能低下が目立ち始めた42倍付近、10コアなら40倍まで実用性能を維持できたこと、通常操作用の52 / 50倍との統合、全体offsetで起きた長時間WHEA、倍率帯ごとに分けたV/F Point、90 Wの電力上限を経て、現在のCPU基本設定に至るまでを記録しています。

## ファンの確認から再開した電圧調整

### 1. [ファンを静かにしたあと、CPU電圧をもう一度詰める](./system-tuning-2026-09-05-ffxiv-voltage.md)

待機中のファンを静かにしたあと、負荷中の冷却をFF14で確認しました。温度も性能もほぼ同じでしたが、V/F設定を変えてもCPU電圧が下がっていないことが気になり、下のポイントやTVBを試し始めました。

### 2. [固定電圧で下限を探し、Ringの倍率を下げてみる](./system-tuning-2026-09-05-manual-voltage-ring.md)

Manualで40倍の電圧を下げていくと、起動失敗やFF14終了後の再起動が起きました。動く電圧の目安をつかみ、倍率を変えながら使う方法を探すうちに、AC Load LineとRingの調整へ進みました。

### 3. [50倍と52倍を詰めると、長時間でWHEAが出た](./system-tuning-2026-09-05-high-ratio-whea.md)

40倍の低い電圧を残して、50倍と52倍も使えるようにします。短い負荷では電圧を詰められましたが、FF14を長く回すとWHEAが出ました。何十分も待たずに再現できないか、負荷の上下も繰り返してみました。

### 4. [DirectXエラーが続いたので、全コア40倍からやり直す](./system-tuning-2026-09-06-ffxiv-long-run.md)

AC Load Lineを少し戻すと、今度はDirectXエラーが出ました。全コア40倍から試し直し、50倍の電圧も戻したところ、50倍と40倍を使い分けたまま2時間を超えて回りました。

## ブラウザ性能と倍率

### 1. [52倍を戻す前に、ブラウザで高倍率の出番を調べる](./system-tuning-2026-09-06-browser-high-ratios.md)

FF14が長く回ったあと、52倍を戻すだけの性能上積みがあるのか気になりました。普段のブラウザ操作からコアの使われ方を調べ、Speedometerで倍率を変えて比較すると、4コアまでの51倍はほとんど観測されませんでした。

### 2. [40倍から探り直して、7～9コアは47倍にする](./system-tuning-2026-09-07-browser-ratio-balance.md)

1設定に約1時間かかる測定を短くし、40・45・47・49倍を試しました。45倍の効率が気になって長い測定へ戻りましたが、性能の8%低下は大きい。47倍と48倍も比べ、7～9コアを47倍に決めたところまでです。この時点では、1～6コアの高倍率はまだ決めていませんでした。

### 3. [ブラウザの測り方を揃え直して、CPU調整を一区切りにする](./system-tuning-cpu-validation-complete.md)

4コアまでの高倍率は、以前から普段のHWiNFO記録に現れていました。IntelとWindowsの動きも調べ、普段の高倍率を残しながら1～6コアを52・51・50倍に分けます。設定変更後はブラウザのスコアが大きく下がり、測定方法を整え直すことになりました。GPUの850 mVと750 mVで性能はほぼ同じで、普段の51倍も確認でき、CPU調整を一区切りにします。その後、52倍の記録も見つかりました。

## GPUの電圧をさらに下げてみる

### [RTX 3080を750 mVまで下げて、普段のゲームで確かめる](./system-tuning-gpu-750mv-dlss.md)

800 mVの高クロック側でDirectXエラーが出たあと、クロックを下げて試し、750 mVまで進みました。DLSSを常時適用すると、FF14ベンチのGPU平均電力は200 W弱になりました。実ゲームでの見え方も比べ、NVIDIA Appの設定変更でボケやにじみがほぼなくなり、約8時間20分の長時間試験を終えたところまでです。
