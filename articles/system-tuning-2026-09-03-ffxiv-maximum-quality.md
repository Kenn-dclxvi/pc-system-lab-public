# FF14ベンチマークを4K最高品質で回し、このPCの実力を測り直す

[← CPU効率編](./system-tuning-2026-09-03-cpu-efficiency.md) / [索引](./system-tuning-2026-09-01-index.md)

ここまでの調整で、普段使うCPUとGPUの設定はひとまず形になりました。ただ、最後に残したFF14ベンチのScore 16,841は「カスタム」です。

これはDLSSを全域へ適用し、パフォーマンスを出しながらGPU負荷と消費電力を下げるために選んだ、私の実用設定です。実際の使い方を見るにはこれでよいのですが、このPCが世の中の構成と比べてどの位置にいるのかを知るには、共通の基準が必要でした。

そこで、公開例の多い4K・最高品質へ条件を戻し、このPCの能力をもう一度測ることにしました。

今回は設定の好みではなく、公開されているスコアと以前の同条件記録を物差しにして、このPCの現在の能力をできるだけ客観的に見ます。

## 4K最高品質で残した基準値

CPUは1～4コア52倍、5～9コア50倍、10コア40倍。倍率帯ごとに分けたV/F Pointと90 Wの電力上限もそのままです。GPUも実用設定の1890 MHz / 850 mVから変えていません。Hypervisor / VBSは無効です。

ベンチマーク側は3840×2160、最高品質、仮想フルスクリーン、DirectX 11です。動的解像度を有効にし、DLSSは60 FPSを下回ったときだけ適用する、最高品質プリセットの条件で測りました。

![FF14黄金のレガシーベンチマーク 4K最高品質 Score 10,845](./images/ffxiv-dawntrail-benchmark-score-10845.png)

| 指標 | 結果 |
| --- | ---: |
| Score | 10,845 |
| Average | 75.10126 FPS |
| Minimum | 51 FPS |
| CPU Package Power平均 | 45.44 W |
| GPU Power平均 | 277.64 W |
| GPU使用率平均 | 99.90% |
| CPU+GPU平均電力 | 323.08 W |

評価は「快適」。WHEA、GPUドライバ、Windows、アプリケーションの異常を示すイベントもありませんでした。

## 公開結果の中では、どこにいるのか

同じ4K・最高品質の公開結果へ並べると、現在の10900KとRTX 3080は次の位置に入ります。

| 構成 | Score |
| --- | ---: |
| Core i9-14900K + RTX 3080 | 10,094 |
| Core i9-14900K + RTX 4070 SUPER | 10,333 |
| **Core i9-10900K + RTX 3080（このPC）** | **10,845** |
| Core i9-14900K + RTX 4070 Ti | 10,936 |
| Core i9-14900K + RTX 3080 Ti | 11,317 |

比較値は[自作とゲームと趣味の日々](https://jisakuhibi.jp/final-fantasy-xiv-dawntrail-benchmark)が同じCPU環境でGPUを入れ替えて測った結果です。別の実機例でも、Core i7-13700FとRTX 4070 Tiの組み合わせがScore 10,750を記録しています（[The Lodestone](https://jp.finalfantasyxiv.com/lodestone/character/35638662/blog/5373960)）。

測定したPCや細かな条件まで同一ではないため、RTX 3080がRTX 4070 Tiと同じGPU性能になったという比較ではありません。ただ、4K最高品質の完成したシステムとして見ると、RTX 4070 SUPERとRTX 4070 Tiの間、それも4070 Tiに近いスコア帯です。

10900KとRTX 3080の組み合わせで、しかもCPUとGPUを効率側へ調整した状態です。一世代分をセッティングで稼いだと思うと、これは少しニヤニヤできます。

## 電力を含めると、このPCの性格が見えてきた

公開結果から分かるのは、おもに性能の位置です。他のPCには同じベンチマーク区間のCPUとGPU電力がないため、システム全体のワット当たり性能までは直接比べられません。

一方、このPCではベンチマーク中の電力を記録しています。GPUは平均99.90%使われながら277.64 W、CPUは平均45.44 Wでした。CPUとGPUを合わせて323.08 Wで、4K最高品質を平均75.10 FPSで動かしています。

新しい世代のGPUだけを見れば、RTX 4070 SUPERやRTX 4070 Tiの方が効率は高いはずです。ただ、PC全体で見ると、CPUが平均45 Wほどで必要な仕事を済ませていることが効いてきます。少なくとも「古い10900KとRTX 3080だから、システム全体でも重いはず」という見え方ではありませんでした。

## 約250 WだったはずのGPUが、278 W使っている

ここで一つ引っかかりました。カスタムの試験ではGPU平均が250 W前後だったのに、今回は277.64 Wです。CPUを低クロック化した分、負荷がGPU側へ寄ったのかと思いました。

記録を戻って確認すると、違いはDLSSの使い方でした。カスタムでは常時適用ですが、最高品質では60 FPS未満でだけ適用されます。今回は平均75 FPSで、GPU使用率も平均99.90%でした。多くの区間では動的解像度による負荷軽減が働かず、GPUをほぼ使い切っていたと考えられます。

つまり、約250 Wと278 WはCPU設定の変化を示す数字ではなく、まず描画条件が違う結果として見るべきでした。

## 同じ最高品質で比べると、電力は約30%下がっていた

さらに、調整前にも同じ4K・最高品質、DLSSは60 FPS未満という条件で測った記録が残っていました。CPUとGPUの調整を重ねる前後で並べると、違いはもっとはっきりします。

| 指標 | 以前の記録 | 現在の設定 |
| --- | --- | --- |
| CPU倍率 | 1～2コア53倍 / 3コア52倍 / 4コア51倍 / 5～6コア50倍 / 7～10コア49倍 | 1～4コア52倍 / 5～9コア50倍 / 10コア40倍 |
| CPU電圧設定 | Manual 1.300 V | Auto / V/F Point 3・4 -80 mV、5・6 -60 mV、7 -40 mV |
| PL1 / PL2 | 4095 W / 4095 W（実質制限なし） | 90 W / 90 W |
| GPU Clock設定 | 2050 MHz | 1890 MHz / 850 mV以上を同じクロックへ固定 |
| GPU Clock平均 | 2066.066 MHz | 1904.27 MHz |
| GPU電圧 | 固定なし（実電圧は未取得） | 0.850 V |
| Score | 11,083 | 10,845 |
| Average | 77.4511 FPS | 75.10126 FPS |
| CPU Package Power平均 | 63.413 W | 45.44 W |
| GPU Power平均 | 395.839 W | 277.64 W |
| CPU+GPU平均電力 | 459.25 W | 323.08 W |

以前はCPUがManual 1.300 Vで、CPUの電力上限も実質ありませんでした。GPUも平均2066 MHzで動いています。現在はCPUの倍率と電圧を使う領域ごとに分け、GPUも850 mV・1890 MHzへ下げています。そのうえで性能は大きく崩さず、CPUとGPUを合わせた平均電力は約30%下がりました。

これはCPUだけ、GPUだけの効果ではなく、両方の動作点を効率側へ移した結果です。カスタムの約250 Wと混ぜず、同じ最高品質どうしで比べたことで、ここまで進めた省電力化の成果がきれいに見えました。

最高品質の方が、このPCの特性をよりはっきり見せてくれたと思います。4KではGPUをほぼ使い切り、その横でCPUは必要な仕事を平均45 Wほどでこなしています。カスタムはパフォーマンスとGPU負荷を両立させる実用設定、最高品質は世の中の基準へ合わせてPC全体の能力を見る設定です。

今回効いたのは、AIに答えを一度で当てさせることではありませんでした。ChatGPTと疑問や見方を整理し、Codexで条件をそろえて測り、結果を残す。数字に違和感があれば過去の記録へ戻り、説明を直す。その往復ができる実験環境を作ったから、最後は「一世代分を稼げた」だけでなく、なぜそう見えるのかまで説明できました。

次は同じ測り方を別のゲームや負荷にも広げ、この効率がFF14だけのものなのか、それとも現在の基本設定の性格なのかを確かめたいと思います。
