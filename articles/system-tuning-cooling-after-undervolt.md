# ケースの冷却を確かめてから、UVとファンの下限を詰める

ケースの吸排気、CPUとGPUの低電圧化、ファンの下限調整は、それぞれの記事で試した順に書いてきました。ここでは、その結果が後の調整にどうつながったのかを整理します。

出発点は、AIOの故障に伴う配置変更でした。Define 7の前面にあったKraken X73を外し、新しいKraken 360を天面排気へ。天面のNoctua 140 mmファン3基は前面吸気に移しています。GPUのUVも試すつもりでしたが、先にこの配置でどこまで冷えるかを確かめました。両方を一度に変えると、どちらが効いたのか分からなくなるためです。

## ケースの確認で、残す風と減らせる回転が分かった

最初は、ケースファンをGPU温度に連動させると背面が平均約1,455 RPM、前面が約1,353 RPMまで上がり、音が気になっていました。カーブを下げてもGPUはほとんど熱くならず、この時点ですでに回転を落とす余地がありました。

底面ファンには、3ピンのDCファンをPWM設定で使っていたため約900 RPMから動かない問題もありました。DC Modeへ直して較正したうえで、風を増やしたり止めたりして比べています。再起動で設定が戻る問題は、その後に制御サービスを切り替えて解消しました。

導風板の付け外しではHotspotが約0.7℃下がったので、板は残しました。その状態で底面を強くすると一度は少し冷えましたが、通常へ戻しても低いままです。さらに増速し、停止設定とも比べた結果がこちらです。

| 底面ファン | 回転数 | GPU平均温度 | Hotspot平均温度 |
| --- | ---: | ---: | ---: |
| 通常：40／60／75℃で38／40／65% | 589 RPM | 66.68℃ | 82.37℃ |
| 増速：同じ温度で80／90／100% | 893 RPM | 66.99℃ | 82.22℃ |
| 全点0%の停止設定 | 停止時のRPMは取得できず | 66.69℃ | 82.52℃ |

GPU使用率50%以上の区間で比べています。この頃のGPUはUV前で、平均約340～350 W。600 RPMほどを900 RPM近くまで上げても冷えず、停止設定でも温度はほぼ同じでした。GPUのために底面を回し続ける理由は見当たりませんでした。

側面を開けてもGPUは66.69→66.30℃と、下がったのは約0.4℃です。一方、背面を停止指定するとGPU温度が約0.5℃上がり、GPUファンも約78 RPM増えました。底面と背面では、止めたときの様子が違います。ただ、背面を約779→1,480 RPMへ増速してもGPUは冷えなかったので、背面は通常のカーブに戻しました。

CPUと水温は側面を開けると下がったため、天面ラジエーターも調べています。100%固定から90%主体、70%主体へ下げた短い試験では、GPU温度はいずれも約67℃。CPU平均は57.80／58.34／60.23℃でしたが、開始水温も33／34／35℃と違っていました。ここでは70%で使い、温度や音が気になったら再調整することにしました。冷却水温への連動を続け、45℃までは70%、50℃で100%になる設定です。

これらを後から並べると、ケースの確認は「どのファンも強くする」状態から、底面は停止設定、背面は通常回転、ラジエーターは70%主体へ落ち着く過程でした。GPUを冷やすために回転をさらに増やす必要を感じなくなり、この状態を基準に、予定していたUVの効果を見られるようになりました。

個々の付け外しやカーブ変更は[ケース冷却編](./system-tuning-2026-09-01-case-cooling.md)にまとめています。

## GPUの発熱が減ると、温度に連動するファンも下がった

RTX 3080は1905 MHz／825 mVだとFF14の途中でDirectXエラーになり、850 mVへ戻すと単発のベンチを完走しました。同じ4Kカスタム設定、DLSS常時適用で従来設定と比べています。

| 項目 | 従来設定 | 1905 MHz／850 mV設定 |
| --- | ---: | ---: |
| Score | 17,674 | 17,082 |
| GPU平均電力 | 350.7 W | 252.8 W |
| GPU平均温度 | 66.84℃ | 58.90℃ |
| Hotspot平均温度 | 83.42℃ | 73.56℃ |
| GPUファン1／2平均 | 1,776／1,774 RPM | 1,072／1,072 RPM |
| 背面／前面ファン平均 | 771／775 RPM | 678／698 RPM |
| 冷却水平均温度 | 36.40℃ | 36.17℃ |

Scoreが約3%下がる代わりに、電力は約100 W減りました。この組み合わせなら、自分の使い方では100 W下がる方を取りたいです。ケース側を変えていたときは1℃に届かない差を見ていましたが、今度はGPUが約8℃、Hotspotが約10℃下がっています。

ここでファン調整につながったのは、温度が下がると、同じカーブでも回転数が下がったことです。GPUファンは約1,800 RPMから1,100 RPMほどになり、GPU温度を見ている前後のケースファンもゆっくり回るようになりました。UVで減らした発熱が、温度と回転数の両方に表れています。

一方、冷却水は両方とも約36℃でした。GPUが8℃下がったからといって、水温も同じようには下がりません。ラジエーターは水温を見て動くので、こちらのカーブを下げる判断には、別に水温の推移を見る必要がありました。

GPUの設定を詰めた経緯は[GPU編](./system-tuning-2026-09-01-gpu.md)に書いています。

## 安定性の試験が、温まった水を冷やせるかの確認にもなった

単発では通った850 mVも、長く回すと約59分で再起動しました。先の底面停止試験ではCPU/cache系の訂正済みWHEAも出ていたため、CPUの最高倍率を全段100 MHz相当下げて再試験しています。GPU設定にも違いのある次の試験では、約3時間22分、WHEAやGPUドライバの異常、再起動なく回りました。

この試験の目的は安定性の確認でしたが、後のファン調整に役立ったのは、長く回したときの水温です。底面は停止設定、ラジエーターは70%主体、GPUは平均約252 Wで動いていました。

| 経過時間 | 冷却水の平均温度 |
| --- | ---: |
| 開始から30分 | 41.50℃ |
| 30～60分 | 43.15℃ |
| 60～90分 | 44.00℃ |
| 90～120分 | 44.00℃ |
| 120～150分 | 44.94℃ |
| 150～180分 | 45.00℃ |

水温は37℃から約2時間かけて45℃まで上がり、その後は終了まで、記録された値が45℃で揃っていました。CPUも温度や電力の制限にかからず動いています。短いベンチでは見えていなかった、十分に水が温まった状態をここで確認できました。

その後、待機中のラジエーターの音が気になり、水温20～35℃を70%から60%、40℃を65%へ下げています。45℃70%と50℃100%は残しました。長時間試験で使っていた温度帯の冷却を保ち、冷えているところだけ回転を落とす変更です。結果的に、安定性を調べた記録が、どこを残して下限を下げるかの目安にもなりました。

## CPUの発熱も減らし、冷えているときの下限を見直した

続くCore i9-10900Kの調整では、FF14で10コアを使うときの倍率を50倍から40倍へ下げ、電圧も調整しました。

| 項目 | 主に50倍で動く設定 | 主に40倍で動く設定 |
| --- | ---: | ---: |
| Score | 17,611 | 16,871 |
| 対象倍率でのVcore中央値 | 1.412 V | 1.190 V |
| CPU平均電力 | 95.21 W | 55.83 W |
| CPU平均温度 | 65.90℃ | 58.20℃ |
| GPU平均電力 | 255.23 W | 254.23 W |

倍率表と自動電圧補正を合わせて変えた結果です。5 GHzから4 GHzへ下げてもScoreの差は約4%で、CPUの電力は約95 Wから56 Wになりました。FF14中に5 GHzで回し続けるのは少しもったいなく思えてきます。普段の操作には高い倍率を残し、10コアを使うときは40倍にする方向へ進みました。詳細は[CPU効率編](./system-tuning-2026-09-03-cpu-efficiency.md)にあります。

GPUに続いてCPUの発熱も減らせましたが、温度が下がってもファンは設定した下限で回り続けます。そこで、待機中の音をもう少し抑えるため、前後のケースファンとGPUファンの下限を下げ、ラジエーターも60%から35%へもう一段下げました。

| 対象 | 下限の変更 | 下限調整後に残した温度の高い側の設定 |
| --- | --- | --- |
| 背面：CPUとGPUの高い方に連動 | 40℃31%→30℃20% | 60℃40%、80℃約59%、さらに高温で100% |
| 前面：GPU温度に連動 | 40℃40%→30℃20% | 60℃40%、80℃60%、さらに高温で100% |
| ラジエーター：水温に連動 | 20～35℃を70%→60%→35% | 40℃65%、45℃70%、50℃以上100% |
| GPUファン1／2：GPU温度に連動 | 30℃50%→30℃30% | 60℃50%、70℃82%、85℃100% |

前後の応答は上昇12秒・下降25秒、ポンプは水温に連動するCAM標準のSilent、底面は停止設定を続けています。

特にラジエーターは、低温側が70%から35%になっても、水温45℃では最初と同じ70%です。発熱を減らす調整と、水が温まるまで見た記録が揃ったことで、負荷中に使う部分を残しながら、待機中の回転を下げる形になりました。

## 負荷中の冷却を残したまま、軽い作業では回転が落ちた

下限を下げる前後は、4K最高品質でも比べています。DLSSは60 FPS未満で適用する条件で、変更前のGPUは平均約278 W。先のカスタム設定より電力を使っている条件でも、冷却が足りるかを見ました。

| 項目 | 下限変更前 | 変更後 |
| --- | ---: | ---: |
| Score | 10,845 | 10,820 |
| 平均FPS | 75.101 | 74.946 |
| GPU最高温度 | 66.4℃ | 66.6℃ |
| Hotspot最高温度 | 81.1℃ | 80.0℃ |
| 冷却水温・開始→終了 | 36→40℃ | 36→40℃ |
| 背面／前面ファン平均 | 722／726 RPM | 724／712 RPM |
| GPUファン1／2平均 | 1,272／1,272 RPM | 1,279／1,278 RPM |

この間にはCPU電圧とGPUクロックも調整しています。変更を合わせた状態で、負荷中の回転数と温度はほぼ同じでした。Scoreも1万点を超える中で25点の差です。この差を気にして下限を戻すほどではないので、下げた設定を使うことにしました。

後の短いブラウザ試験では、水温34℃、GPU平均33.6℃で、背面は平均472 RPM、前面は374 RPMでした。前面の回転数は3基のうち1基の記録です。ゲーム中の700 RPM台に対して、軽い作業では回転が落ちています。

ここまでをつなげて見ると、UVで温度が下がり、まず温度カーブに沿ってファンが遅くなりました。そのあと下限も見直したことで、冷えているときにさらに落とせるようになっています。負荷中は必要な回転まで上がる設定を残せたことが、両方を進めるうえで役立ちました。

## その後のUVと、ベンチ中の音

その後、GPUを1740 MHz／800 mVから1620 MHz／750 mVへ下げた単発比較でも、同じ4K最高品質で電力と回転数が下がりました。

| 項目 | 1740 MHz／800 mV設定 | 1620 MHz／750 mV設定 |
| --- | ---: | ---: |
| Score | 10,680 | 10,611 |
| GPU平均電力 | 235.71 W | 207.68 W |
| GPU平均温度 | 60.47℃ | 59.28℃ |
| GPUファン1／2平均 | 985／990 RPM | 880／888 RPM |
| 背面／前面ファン平均 | 700／683 RPM | 687／667 RPM |
| 冷却水温・開始→終了 | 36→37℃ | 36→37℃ |

クロックと電圧は保存設定です。実測平均は1763→1650 MHz、793.75→750 mVでした。Scoreは約0.65%の差で、さらに約28 W減っています。ファンカーブを変えなくても、GPUファンは1,000 RPM近くから900 RPMを切るくらいになりました。

下限を30%にした直後のブラウザ試験ではGPUファンが実測50%でしたが、この比較では50%未満でも動いています。設定値に加えて、実際の回転数も見ながら調整を続けました。750 mVと、その後のDLSS常時適用・Preset Kでの長時間試験は[GPU 750 mV編](./system-tuning-gpu-750mv-dlss.md)にまとめています。

その長時間ベンチを2時間回したところで、リアファン横の音も測りました。UV前、ファンの初期調整中に同じ場所で測った記録と並べたものです。

| 騒音アプリの表示 | ファンの初期調整中・UV前 | 750 mVのベンチを2時間回したあと |
| --- | ---: | ---: |
| AVG（平均表示） | 52.5 dB | 43.3 dB |
| MAX（最大表示） | 56.2 dB | 45.9 dB |
| 画面の時間表示 | 1分22秒 | 15秒 |

時間表示の異なる2回の記録を並べると、アプリのAVG表示は以前より約9 dB低い値になっていました。

一般的な聞こえ方の目安では、同じ種類の音が10 dB下がると、耳に感じる大きさはおよそ半分になります。約9 dBの差も、この「半分くらいの大きさに聞こえる」に近い差です。音の高さや周囲の音で感じ方は変わりますが、数字から聞こえ方を想像する目安になります。参考：[NIDCDによる音の大きさの説明](https://www.nidcd.nih.gov/health/how-sound-measured)。
